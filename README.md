# 💳 Online Course Plans

A simple **Online Course Plans** landing page built with **HTML & CSS** as part of my **Front-End Development learning journey at SEF Academy**.
The project presents different course subscription plans in a clean pricing-card layout, with an interactive navigation bar and hover effects.

##  Features

- Navigation bar with multiple links
- Three pricing plans: Basic, Standard, and Professional
- Clear pricing and plan features
- Interactive hover effects
- Clean and organized card layout
- Responsive-style visual structure

## 🛠️ Technologies

- HTML5
- CSS3

### Concepts Practiced

- HTML Structure
- CSS Positioning & Layout
- Floating Elements
- Borders & Border Radius
- Navigation Menus
- Hover Effects
- Styling Buttons and Cards
